## Usage

### What is this?

This mod automatically fills in **unexplored** areas on Xaero's World Map with biome and terrain data generated from the world seed. No more staring at black void at the edge of your map — see predicted biomes, terrain elevation, and lighting as if you'd been there.

### What can you do with it?

- **Quickly locate biomes** — spot deserts, swamps, cherry groves at a glance without wandering blindly
- **Plan exploration routes** — check the terrain before heading out: find mountains, oceans, rivers
- **Efficient seed-based exploration** — seed preview tells you exactly where to go

### Features

- Multi-level zoom biome preview, seamlessly integrated with Xaero's map
- Terrain elevation rendering + lighting shadows (overworld only)
- 3-tier exploration detection — explored areas keep real data, only fills unexplored gaps
- Three color schemes: Native (default), Vanilla, Legacy — switchable from side panel
- **Structure icons** — 26 structure types, individually toggleable from side panel
- **Settings panel** — SM button on the right side of the map, per-biome/structure toggle, icon size slider
- Seed history (capped at 1000, MRU-ordered)
- Multiplayer support — each server stores its own seed and settings independently
- Client-side only, no server installation required

### How to use

1. Install dependencies: Xaero's World Map, Fabric API
2. Press `M` to open the fullscreen map
3. **Singleplayer**: seed is read automatically, map displays immediately
4. **Multiplayer**: enter the seed in the world switching screen (`GuiMapSwitching`)
5. Click the **SM** button on the right side to open the **settings panel**:
   - Toggle individual biome types (show/hide specific biomes)
   - Toggle individual structure types (show/hide specific structures)
   - Adjust structure icon size (0.05~2.0x)

## For Developers

### Architecture

Fabric mod that injects into Xaero World Map's rendering pipeline via Mixin, uses the cubiomes native library for fast biome/terrain generation, and renders as overlaid textures on the map.

#### Core Components

- **C Native Layer** (`src/main/c/xsm/apis/render.cpp`) — cubiomes-based biome/structure/terrain generation and lighting, compiled to `libxsmcore.so` (Linux) / `xsmcore.dll` (Windows) / `libxsmcore.dylib` (macOS)
- **Java FFM Bindings** (`src/client/.../nativeapi/Xsm.java`) — FFM interface generated by jextract to call C functions
- **Cache System** (`CellCache` + `StructureCache` + `QueryPointCache`) — multi-level (1, 4, 16, 64, 256) GPU texture cache + structure query cache, async generation
- **Side Panel** (`SeedMapPanel`) — settings panel opened by the SM button, per-biome/structure toggle, icon size slider
- **7 Mixins** — `SeedMapMixin` (render), `SeedMapCursorMixin` (cursor info), `SeedMapToggleMixin` (toggle), `XsmMainPanelMixin` (side panel), `WorldSwitchMixin` (world switch), `GuiMapSwitchingMixin` (seed input), `StructureOverlayMixin` (structure icons)

#### Render Pipeline

1. Injected after Xaero's second draw pass in `GuiMap.extractRenderState`
2. Cell zoom level selected by `userScale` (1, 4, 16, 64, 256)
3. Iterate visible Xaero `LeveledRegion`s within viewport
4. Regions without Xaero data: fill entire cell with seed data
5. Regions with Xaero data: 3-tier decision tree detects exploration, fills only unexplored sub-tiles
6. SuperScale (×4) fallback + SubScale (÷4) overlay strategy

#### Exploration Detection (3-Tier)

For each 16×16 sub-tile:

1. **L1**: leaf `MapRegion` — `hasHadTerrain() == false` confirms unexplored
2. **L2**: `MapTileChunk` — `hasHadTerrain() == false` confirms unexplored
3. **L3**: `RegionTexture.getHeight() != 32767` means explored

`region == null` or `chunk == null` does **not** mean unexplored — must fall through to L3 final check via `getHeight()`.

### Building

#### Prerequisites

- Java 25
- git submodule (cubiomes)

#### Commands

```bash
git submodule update --init
./gradlew build -x compileNativeWindows   # Linux .so + JAR
./gradlew runClient                       # Launch Minecraft
```

Optional flags:

| Flag                          | Effect                              |
| ----------------------------- | ----------------------------------- |
| `-PjextractPath=/path/to/ext` | Use local jextract copy             |
| `-PskipNativeBuild`           | Skip native compilation (Java only) |
| `-PskipNativeWindows`         | Skip Windows cross-compilation      |

`gradle.local.properties` (gitignored) can be used to persist local property overrides.

#### C Unit Tests

```bash
cmake -S src/main/c -B build-test -DCMAKE_BUILD_TYPE=Release
cmake --build build-test --target xsmtest
./build-test/xsmtest
```

Add `-DDEBUG_TIMINGS=ON` to enable performance timing.
